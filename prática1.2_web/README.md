# Desafio Final - Parte 2

Página de produtos, feita apenas com HTML.
(Criei a página da loja de biscoitos gatinho - Inspirada em Steven Universo)

## Conteúdo
- Título principal e descrição da loja
- 3 produtos, cada um com imagem, nome, preço e link para detalhes
- Formulário para cadastrar novo produto

## Estrutura semântica usada
`header` (título), `main` (conteúdo), `section` (produtos e cadastro), `footer` (rodapé)

## Como abrir
Abrir o arquivo `loja-biscoito-gatinho.html` em qualquer navegador.

# Prática 2 - Estilização com CSS

Estilização da página "Loja de Biscoitos Gatinho" usando `style.css` puro.

## Arquivos
- `main.html`
- `style.css`

## Propriedades obrigatórias usadas
`color` / `background-color`, `font-size`, `padding` / `margin`, `border` / `border-radius`, `width`, `display: flex`

## Elementos estilizados
body, títulos, parágrafos, links, imagens, cards de produtos, botões, formulário e tabela

## Desafio Extra (responsivo)
Cards de produtos e menu do footer ficam em linha no desktop e empilham em coluna no celular, via `@media (max-width: 600px)`.

## Como abrir
Abrir o arquivo `main.html` em qualquer navegador (com `style.css` na mesma pasta).

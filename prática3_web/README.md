# Prática 3 - Interatividade com JavaScript

Página "Loja de Biscoitos Gatinho" tornada interativa com `script.js` puro (sem back-end).

## Arquivos
- `index.html`
- `style.css`
- `script.js`

## Funcionalidades
- **Botão "Comprar":** ao clicar, exibe a mensagem "Produto adicionado ao carrinho!" e destaca o card do produto por 3 segundos.
- **Campo de busca:** ao clicar em "Pesquisar", filtra os cards pelo nome do produto.
- **Validação do formulário:** não permite o envio se Nome, E-mail ou Mensagem estiverem vazios, exibindo um alerta e marcando o campo com borda vermelha.
- **Interação visual:** classes CSS alteradas via JavaScript, sem escrever estilos inline para isso.

## Como abrir
Abrir o arquivo `index.html` em qualquer navegador (com `style.css` e `script.js` na mesma pasta).
